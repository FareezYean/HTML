Apa itu Typography dalam Web

Typography dalam Website adalah seni mengatur huruf di halaman web agar teks mudah dibaca, menarik, dan konsisten di berbagai perangkat.

Ini mencakup pemilihan font, ukuran, warna, spasi, serta tata letak teks untuk menciptakan tampilan yang nyaman dan estetis bagi pengguna.
